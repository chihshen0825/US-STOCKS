# 短線技術面儀表板 (3 檔)

Chrome / Edge MV3 擴充功能。**點工具列圖示在新分頁開啟全螢幕儀表板**，同時監看 3 檔美股，可調 **1–5 秒**自動更新。

## 安裝

1. 開啟 `chrome://extensions` 或 `edge://extensions`
2. 右上開啟「**開發人員模式**」
3. 「**載入未封裝項目**」→ 選 `c:\Temp\Case\shortterm-stock-dashboard`
4. 點工具列圖示 → 自動在新分頁開啟儀表板（如已開啟會切換到該分頁）

## 操作

| 按鈕 | 功能 |
|------|------|
| ⟳ | 立刻手動刷新 |
| ⚙ | 編輯 3 檔代碼（空白或逗號分隔） |
| ☑ 自動 3 秒 | 取消可暫停自動刷新 |

## 預設股票

INTC、AMD、STX、PLTR、MSFT、GOOGL（可自訂）

## 注意事項

- 1–5 秒 × 3 檔，負載遠低於一般 API 限制
- 美股開盤外資料不會即時變動
- **信號為當下技術讀值，不構成投資建議**


## 顯示內容（每張卡片）

- 股票代碼 + 公司名稱
- **短線信號**：STRONG BUY / BUY / HOLD / SELL / STRONG SELL（含 score）
- 即時股價、漲跌、漲跌幅
- 60 分鐘迷你走勢圖（漸層填色）
- MACD-Hist、RSI(14)、量能比（近 5 分均量 ÷ 全日均量）、日內高/低
- 正面 / 負面新聞數量 + 最新標題
- 信號理由（聚合各因子說明）

## 短線建議計分邏輯（純技術面，**不預測未來**）

| 因子 | 計分 |
|------|------|
| 現價 vs 前收 | ±1 |
| 現價 vs MA20 (近 20 分均) | ±1 |
| 現價 vs MA60 (近 60 分均) | ±1 |
| MACD Hist 方向 | ±1 / ±2（擴張） |
| RSI 區間 | 超買 −1、超賣 +1、強勢 +0.5、弱勢 −0.5 |
| 量增（>1.5x） | 強化現有方向 ±1 |
| 新聞情緒明顯偏向 | ±0.5 |

| score | 信號 |
|------|------|
| ≥ +5 | STRONG BUY |
| +2 ~ +4.5 | BUY |
| −1.9 ~ +1.9 | HOLD |
| −2 ~ −4.5 | SELL |
| ≤ −5 | STRONG SELL |

## 安裝

1. 開啟 `chrome://extensions` 或 `edge://extensions`
2. 開啟「開發人員模式」
3. 「載入未封裝項目」→ 選 `c:\Temp\Case\shortterm-stock-dashboard`
4. 點工具列圖示開啟 popup（寬 980px）

## 重要注意事項

- **1 秒更新會對 Yahoo Finance 公開 endpoint 發出較頻繁請求**（6 req/s）。若被暫時封鎖，卡片會出現紅框，下個刷新週期會自動重試。可關閉「自動 1 秒」改用手動刷新。
- 開盤外（夜間 / 假日）僅顯示最後成交資料，不會即時變動。
- **信號為當下技術讀值，不構成投資建議**。短線交易具高度風險。
